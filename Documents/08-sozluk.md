# Sözlük

Dokümandaki Türkçe ve İngilizce terimlerin karşılıkları ve kısa tanımları.

## Terimler

| Türkçe | İngilizce | Tanım |
| --- | --- | --- |
| Marka | Brand | Okulların bağlı olduğu üst çatı; en geniş yetki kapsamı |
| Okul | School | Marka altındaki fiziksel okul; kendi eğitim yılı ve ayarları vardır |
| Eğitim yılı (eğitim-öğretim yılı) | Academic year | Okul bazında yıllık dönem; bir aktif, bir planlanan |
| Dönem | Term | Gelişim raporu dönemleri (varsayılan iki) |
| Yaş grubu | Age group | Doğum tarihi kuralına göre sınıf gruplaması |
| Sınıf | Classroom | Okul, yıl ve yaş grubu birimi; sorumlu ve yardımcı öğretmenleri vardır |
| Kişi kaydı (öğrenci) | Student (person record) | Çocuğun kalıcı kimlik kaydı; okuldan bağımsız |
| Kayıt | Enrollment | Çocuğun bir yılda bir okul ve sınıfa bağlı kaydı; işlem verisi buna bağlanır |
| Veli | Guardian / parent | Çocuktan sorumlu yetişkin; tam, sınırlı veya kısıtlı yetki düzeyi |
| Teslim yetkilisi | Authorized pickup person | Çocuğu teslim alabilecek, veli tarafından tanımlı kişi |
| Nakil | Transfer | Çocuğun marka içinde başka okula geçmesi; kişi kaydı korunur |
| Mezuniyet / ayrılış | Graduation / withdrawal | Kaydın sona ermesi; 08'deki erişim ve saklama akışını başlatır |
| Salt-okunur süre | Read-only grace period | Mezuniyet sonrası velinin yalnızca okuyup indirebildiği süre (varsayılan 30 gün) |
| Veri paketi | Data export package | Velinin indirdiği rapor, portfolyo ve fotoğraf arşivi |
| Anonimleştirme | Anonymization | Kişisel alanların kişiyle ilişkilendirilemeyecek hale getirilmesi |
| Yasal bekletme | Legal hold | İhtilaf veya resmi talep nedeniyle silmenin durdurulması |
| Yoklama | Roll call / attendance | Günlük devam kaydı |
| Devamsızlık bildirimi | Absence notice | Velinin önceden bildirdiği devamsızlık |
| Gözlem notu | Observation note | Öğretmenin gelişim alanıyla etiketlediği kısa not |
| Gösterge / kazanım | Indicator / learning outcome | Gelişim alanı altında değerlendirilen ölçüt |
| Gelişim raporu | Development report | Dönemlik değerlendirmenin veliyle paylaşılan çıktısı; dönem raporu ile aynı şey |
| Portfolyo | Portfolio | Çocuğun çalışma örnekleri (Faz 2) |
| BEP | Individualized education program | Bireyselleştirilmiş Eğitim Programı; destek planı işaretiyle anılır |
| MEB Okul Öncesi Eğitim Programı | MoNE preschool curriculum | Gösterge kataloğunun dayandığı resmi program (güncel sürümü doğrulanmalı) |
| Duyuru | Announcement | Tek yönlü, kapsamlı bilgilendirme |
| Okudum onayı | Read acknowledgement | Velinin duyuruyu okuduğunu zaman damgasıyla onaylaması |
| İzin formu | Permission slip | Etkinlik için velinin uygulama içi onayı (Faz 2) |
| Sessiz saatler | Quiet hours | Bildirimlerin ertelendiği saat aralığı (varsayılan 18:00–08:00 ve hafta sonu); acil aşar |
| Günlük rapor | Daily report | Yemek, uyku, tuvalet ve etkinlik akışı (Faz 3) |
| Rıza | Consent | KVKK kapsamında açık rıza kaydı; geri alınabilir |
| Aydınlatma metni | Privacy notice | KVKK bilgilendirme metni; sürümlü onaylanır |
| Özel nitelikli kişisel veri | Special category personal data | Sağlık gibi daha sıkı korunan veri |
| KVKK | Personal Data Protection Law (No. 6698) | Türkiye'nin kişisel veri kanunu |
| VERBİS | Data Controllers' Registry | Veri sorumluları sicil bilgi sistemi |
| Veri sorumlusu / veri işleyen | Data controller / processor | Veriyi işleme amacını belirleyen / onun adına işleyen taraf |
| Denetim izi | Audit trail | Kimin ne zaman ne yaptığının değiştirilemez kaydı |
| Çok kiracılı | Multi-tenant | Birden çok marka veya okulun aynı sistemde izole çalışması |
| RLS | Row-level security | Veritabanında satır düzeyi erişim süzgeci |
| Tek kullanımlık kod (OTP) | One-time password | SMS ile gelen giriş kodu |
| TOTP | Time-based one-time password | Uygulama tabanlı ek doğrulama kodu |
| Anlık bildirim | Push notification | Cihaza iletilen bildirim |
| FCM | Firebase Cloud Messaging | Anlık bildirim altyapısı |
| REST API / OpenAPI | REST API / OpenAPI | Uygulama ve panelin konuştuğu arabirim ve sözleşmesi |
| Modüler tek parça | Modular monolith | Tek dağıtım birimi, içeride net modül sınırları |
| Outbox deseni | Outbox pattern | Olayların veritabanı işlemiyle birlikte güvenle yayınlanması |
| MVP | Minimum viable product | İlk kullanılabilir sürüm |
| MoSCoW | Must / Should / Could / Won't | Önceliklendirme ölçeği |
| NFR | Non-functional requirement | Performans, güvenlik gibi işlevsel olmayan gereksinim |
| RPO / RTO | Recovery point / time objective | Kabul edilen veri kaybı ve kurtarma süresi |
| p95 | 95th percentile | İsteklerin %95'inin altında kaldığı değer |
| Kapı | Stage gate | Faz geçişinde karşılanması gereken kriter seti |
| Servis hostesi | Bus attendant | Servis aracında biniş-inişi kaydeden personel (Faz 3) |
| Değerlendirme (dönemlik) | Periodic assessment | Öğretmenin dönem sonunda doldurduğu gösterge formu; yayınlanan çıktısı dönem raporudur |
| Dönem raporu | Term report | Değerlendirmenin veliyle paylaşılan çıktısı; dokümanda “gelişim raporu” ile aynı anlamda |
| Metrik | Metric / KPI | Yönetim raporlarındaki sayısal ölçüt (devam oranı, okunma oranı); gelişim göstergesiyle karıştırılmaz |
| Okul takvimi | School calendar | Eğitim yılındaki gün türleri (okul günü, tatil, yarım gün, kapalı); yoklama ve bildirim zamanlaması buna bağlıdır (01) |
| Olay kataloğu | Event catalogue | Bildirim üreten olayların alıcı, öncelik, kanal ve zamanlama listesi (09) |
| Değişiklik kurulu | Change board | Kapsam ve faz değişikliklerine karar veren kurul: proje sahibi, marka yöneticisi, ürün sorumlusu, teknik lider; iki haftada bir toplanır (Yol Haritası) |
| Eğitim koordinatörü | Education coordinator | Markanın eğitim programından sorumlu kişi; gelişim modülü kararlarının sahibi (S9–S11) |
| E.164 | E.164 | Uluslararası telefon numarası biçimi (+90 ile başlar) |
| Self-servis kayıt | Self-service signup | Bir kurumun kendi kendine hesap açıp platformu kullanmaya başlaması; kapsam dışı (K1) |
| White-label | White-label | Ürünün başka bir markanın adı ve görünümüyle sunulması; kapsam dışı (K1) |
| Idempotency anahtarı | Idempotency key | Aynı isteğin tekrar gönderilmesinde işlemi iki kez uygulatmayan tekil anahtar (çevrimdışı senkron, olay kuyruğu) |
| PITR | Point-in-time recovery | Veritabanını işlem günlüğünden belirli bir ana geri döndürme |
| BYOD | Bring your own device | Personelin kişisel telefonunu iş için kullanması; R15 |
