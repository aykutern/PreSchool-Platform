# PreSchool-Platform

Bir markaya bağlı birden çok anaokulunu tek sistemde yöneten, mobil öncelikli bir platform. Veliler ve öğretmenler tek mobil uygulamayı (Veli ve Öğretmen modları), okul yönetimi web panelini kullanır. Proje analiz aşamasındadır; geliştirme henüz başlamadı.

Analiz dokümanı (genel bakış, modüller, veri modeli, teknik mimari, yol haritası, riskler ve açık sorular): [Docs/](Docs/README.md)
